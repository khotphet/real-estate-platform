รายละเอียดทรัพย์ (Description)

ห้องสวยสภาพมือหนึ่ง เจ้าของเดิมดูแลอย่างดี ตกแต่งครบสไตล์โมเดิร์นพร้อมลากกระเป๋าเข้าอยู่ทันที อยู่ชั้น 8 อาคาร B ทิศเหนือแดดไม่ส่องตอนบ่าย ลมโกรกโปร่งสบายตลอดวัน มองเห็นวิวสระว่ายน้ำส่วนกลางชัดเจน เงียบสงบไม่มีเสียงรบกวนจากถนนใหญ่

รายการของแถมและเฟอร์นิเจอร์:

  • ชุดเฟอร์นิเจอร์บิวท์อินตู้เสื้อผ้า และชั้นวางทีวีเข้าชุด
  • โซฟาผ้าปรับระดับ + โต๊ะรับประทานอาหารพร้อมเก้าอี้ 2 ที่นั่ง
  • เครื่องปรับอากาศ Daikin Inverter จำนวน 2 เครื่อง (ห้องนั่งเล่น และห้องนอน)
  • ตู้เย็น 2 ประตู ขนาด 7.4 คิว และ ไมโครเวฟ
  • เครื่องทำน้ำอุ่น Panasonic พร้อมฉากกั้นอาบน้ำกระจกนิรภัย
  • ผ้าม่านกัน UV 2 ชั้น ติดตั้งครบทุกบาน

ทำเลศักยภาพสูงใจกลางเมืองอุดรธานี เชื่อมต่อทุกการเดินทาง สะดวกใกล้สถานีรถไฟอุดรธานี ตลาดปรีชา ยูดีทาวน์ (UD Town) และศูนย์การค้าเซ็นทรัลพลาซา อุดรธานี เหมาะทั้งซื้อเพื่ออยู่อาศัยเอง หรือซื้อเพื่อปล่อยเช่า yield สูงถึง 6.2% ต่อปี
