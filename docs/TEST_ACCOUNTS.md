# MapNest — บัญชีผู้ใช้สำหรับทดสอบระบบ (Test Accounts Matrix)

เอกสารนี้รวบรวมรายชื่อบัญชีผู้ใช้งานสำหรับทดสอบระบบ **MapNest (แพลตฟอร์มอสังหาริมทรัพย์จังหวัดอุดรธานี)** ทั้ง 4 บทบาทหลัก (Role-Based Access Control - RBAC) ซึ่งได้รับการ Seed ข้อมูลลงใน PostgreSQL ฐานข้อมูลจริง (`m1_identity.users` และ `m1_identity.user_roles`) และระบบยืนยันตัวตน Frontend (`AuthContext`)

## 3. วิธีการเข้าสู่ระบบและทดสอบ

### วิธีที่ 1: คลิกเดียวผ่านแถบ Quick Test Login (สะดวกที่สุด)
1. เปิดเว็บไซต์ที่ `http://localhost:3000`
2. คลิกปุ่ม **"เข้าสู่ระบบ"** บน Navbar ด้านบนขวา
3. จะปรากฏหน้าต่างป๊อปอัปที่มีการ์ดของทั้ง 4 บทบาท
4. คลิกที่บทบาทที่ต้องการทดสอบ เช่น **"นายหน้า Pro"** หรือ **"แอดมิน"**
5. ระบบจะเข้าสู่ระบบให้ทันทีโดยไม่ต้องกรอกข้อมูล

### วิธีที่ 2: จำลองการรับรหัส OTP จริง
1. เปิดหน้าต่างเข้าสู่ระบบ
2. กรอกเบอร์โทรศัพท์ของบัญชีใดก็ได้ตามตารางข้างต้น เช่น `081-882-9901`
3. กดปุ่ม **"ขอรับรหัส OTP"**
4. กรอกรหัส OTP ทดสอบ: **`123456`**
5. กดยืนยัน ระบบจะยืนยันตัวตนสำเร็จทันที

### วิธีที่ 3: สลับบทบาท (Role Switcher) โดยไม่ต้องล็อกเอาท์
1. เมื่อล็อกอินอยู่ คลิกที่รูปโปรไฟล์ที่มุมขวาบนของ Navbar
2. เลือก **"สลับบัญชีทดสอบ (Switch Account)"**
3. เลือกบทบาทใหม่ที่ต้องการสลับ ระบบจะเปลี่ยนสิทธิ์และเมนูของ Navbar ให้ตรงตามบทบาทใหม่ทันที

### วิธีที่ 4: ทดสอบในฐานะ Guest (บุคคลทั่วไป)
1. คลิกที่รูปโปรไฟล์ -> เลือก **"ออกจากระบบ"**
2. ทดสอบเข้าถึง URL หวงห้าม เช่น `/admin` หรือ `/my-listings`
3. ระบบจะแสดงหน้าจอแจ้งเตือนให้เข้าสู่ระบบ หรือแสดงข้อความสิทธิ์ไม่เพียงพอพร้อมปุ่มนำทางกลับหน้าแรก

## 4. โครงสร้างข้อมูลใน PostgreSQL

ข้อมูลผู้ใช้ทั้งหมดถูกเชื่อมโยงตาม schema ในตารางดังนี้:
- **`m1_identity.users`**: ตารางข้อมูลผู้ใช้หลัก (UUID, `display_name`, `phone_e164`, `email`, `avatar_url`)
- **`m1_identity.user_roles`**: ตารางกำหนดสิทธิ์ (`user_id`, `role`, `status`)
- **`m1_identity.agent_profiles`**: ตารางข้อมูลโปรไฟล์นายหน้าสำหรับ Co-Broker และ Microsite

คำสั่งตรวจสอบข้อมูลใน Docker PostgreSQL:
```bash
docker exec mapnest-pg psql -U postgres -d postgres -c \
  "SELECT u.id, u.phone_e164, u.display_name, r.role FROM m1_identity.users u JOIN m1_identity.user_roles r ON u.id = r.user_id ORDER BY u.phone_e164;"
```
